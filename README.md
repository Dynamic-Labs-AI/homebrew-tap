# Dynamic Labs Homebrew tap

```sh
brew tap dynamic-labs-ai/tap
```

| Package | Install | What it is |
|---|---|---|
| **klctl** | `brew install klctl` | KubeLord control CLI: app settings, zero-downtime rollouts and cost. [Guide](https://github.com/Dynamic-Labs-AI/klctl#readme) |
| **truzt** | `brew install truzt` | Truzt secure mesh network client |
| **truzt** (desktop) | `brew install --cask truzt` | Truzt Desktop client |

Upgrade everything from this tap with `brew upgrade`, or one package with `brew upgrade <name>`.

## How packages get here

The formulas are **generated by each product's release pipeline**, so don't edit them by hand;
the next release overwrites them.

| File | Written by |
|---|---|
| `Formula/klctl.rb` | `Dynamic-Labs-AI/klctl` → `.github/workflows/release.yml` (`scripts/homebrew-formula.sh`) |
| `Formula/truzt.rb`, `Casks/truzt.rb` | the Truzt release pipeline |

klctl's archives are downloaded from `https://pkgs.dynamic-labs.ai/Dynamic-Labs-AI/klctl/releases/…`,
and each one is verified against the SHA-256 recorded in the formula.
